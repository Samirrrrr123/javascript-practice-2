# Практическая работа №2

Приложение на Vue 3 с роутингом и авторизацией через DummyJSON.

## Запуск

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev
```

Открыть адрес из терминала.

## Страницы

- `/home` — главная страница.
- `/users` — список пользователей.
- `/login` — вход по логину и паролю.
- `/profile` — профиль авторизованного пользователя.

Токен сохраняется в localStorage под ключом `token`.
Без токена при переходе в профиль открывается страница входа.

Для проверки входа: логин `emilys`, пароль `emilyspass`.
